# Kongo Gaz — Notes pour l'agent

Application de livraison de gaz GPL à domicile à Kinshasa (RDC), construite avec
TanStack Start (Vite + Nitro), React, TypeScript, Tailwind CSS v4 et Supabase.

## Commandes de vérification

- `npm run lint` — ESLint sur tout le projet.
- `npm run build` — build de production (client + serveur Nitro Cloudflare).
- `npm run dev` — serveur de développement (port 8080).
